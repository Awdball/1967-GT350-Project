# 1967 Shelby GT350 Restomod Project

Persistent build documentation, parts cross-referencing, and compatibility tracking for a **1967 Shelby GT350 Restomod** built for **Street, Autocross, and Road Course** driving.

## Build Philosophy & Goals
- **Dual-Purpose Performance:** Responsive street manners combined with road-course/autocross durability (baffled oil control, high-flow cooling, strong braking/chassis geometry).
- **100% Mechanical Fallback (SHTF Resilience):** Every critical system should either be purely mechanical or allow a straightforward, low-effort fallback to a 100% mechanical setup.
- **Shade-Tree Serviceability:** Favor widely available, well-documented components that a capable shade-tree mechanic can diagnose and repair without proprietary tools or dealer-only diagnostics.

## Powertrain Summary (Acquired)
- **Engine:** FordStrokers **363 Liberator** (Dart SHP 4-bolt block, `4.125" × 3.400"`, forged internals, **0 oz internally balanced**, `10.2:1` compression) — *undressed longblock*
- **Top End:** AFR 195 Competition heads (`#1381`, 58cc, angle-plug, `+0.125"` raised exhaust ports), Trick Flow 1.6 roller rockers, Edelbrock RPM Air-Gap (`#7521`) 4150 intake
- **Oiling:** Moroso 7-qt road-race baffled front-sump pan (`#20535`) + Melling `M68` pump
